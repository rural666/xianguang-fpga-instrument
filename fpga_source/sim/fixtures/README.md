# Reference fixtures

`ima_reference.txt` comes from CPython `audioop.lin2adpcm`; each line stores two PCM inputs, their packed code byte, final predictor and step index. It is independent of the HDL encoder.

`adpcm6_reference.txt` is generated by `scripts/make_codec6_vectors.py` and its separate level-table reference.

`speaker_conditioner.hex` is generated by `scripts/make_speaker_vectors.py`: silence, single-frequency signals, high-level signals, a chord and a silence tail.

These data files contain generated numeric samples only. They are included so a clean clone can run the HDL tests directly.
