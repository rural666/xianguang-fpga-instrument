# 键盘输入与FPGA串口接口

输入平台层采用标准USB HID键盘报告。低八度C4..B4映射 `Z S X D C V G B H N J M`；高八度C5..B5映射 `Q 2 W 3 E R 5 T 6 Y 7 U`。修饰键、滚键错误和异常报告由输入层保护处理。键盘本身支持同时报告的按键数量取决于其报告协议和设备能力；FPGA支持24声部不等于普通键盘支持24键同时报告。

| 操作 | 按键 |
| --- | --- |
| 曲谱播放/暂停 | F1 |
| 短示范 | F2 |
| 姿态控制开关 | F3 |
| 锁定姿态音量 | F4 |
| 音量恢复100%并锁定 | F5 |
| 解锁并重新校准姿态 | F6 |
| 空间效果 / 颤音 | F7 / F8 |
| 延音锁定 / 临时延音 | F9 / 空格 |
| 节拍器开关、降速、加速 | F10 / F11 / F12 |
| 上下曲谱 | 左右方向键 |
| 开始/结束录制 | Insert |
| 八度升降 | PageUp / PageDown |
| 音量增减 | = / -，每档10% |
| 全部静音 | Esc |

以上是 `触摸界面交互源码/instrument_keys.c` 的映射规则；该文件依赖平台层，仓库不包含其完整可独立烧录平台工程。

FPGA UART为230400bps。原子控制包为6个ASCII字符 `K VVV C ;`（不含空格），K为类型、VVV为3位大写十六进制、C为校验。

| 包类型 | 负载 |
| --- | --- |
| Q / H | 低/高八度12位琴键位图 |
| ! | 主音量0..256 |
| T | BPM为0关闭，或40..240 |
| S | 曲谱/录制状态 |
| D | USB诊断状态 |

校验为三个负载半字节异或，再异或常量：音量包用0x5，其余包用0xA。示例：`!1004;`设置100%音量，`Q000A;`和`H000A;`清空两组琴键。协议以 `control_top.v` 为准。

FPGA也保留单字符控制和旧12键映射用于串口调试；它与USB输入层的24键映射是两个接口，使用完整键盘时由平台层发送Q/H包。
