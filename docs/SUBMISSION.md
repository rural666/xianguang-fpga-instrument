# 参赛提交准备

以下根据用户提供的作品管理页面截图整理，不代表对其他版本规则的查询。

| 项目 | 截图要求 |
| --- | --- |
| 演示视频 | MP4，AVC/H.264，3分钟内，300MB内 |
| 技术文档 | PDF，50MB内 |
| 全部代码 | RAR，200MB内 |
| 承诺及使用授权书 | PDF，50MB内，需要对应模板与真实签署 |
| 作品海报（选填） | PDF或PPT，50MB内 |
| GitHub链接 | 填写公开仓库URL |
| 作品全貌图 | 实际作品照片 |

作品材料不出现学校名称、指导教师姓名等与作品无关的信息。本仓库不写入此类身份信息；提交前还应检查视频口播、照片背景、PDF属性与文件名。

GitHub下载的ZIP不能只改扩展名当作RAR。代码提交栏需使用真实RAR格式压缩仓库代码。本仓库源代码与设计预览不替代演示视频、技术报告、真实签署文件或实物照片。
