# v2.1.2 硬件与接线

以 `fpga_source/constraints/tang20k_hdmi.cst` 为权威引脚分配。开发板 Tang Nano 20K，板卡修订3923。板载器件信号使用FPGA封装管脚，外接模块根据开发板丝印核对。

| 模块/信号 | 连接 |
| --- | --- |
| GY-521 SCL | 开发板丝印25 |
| GY-521 SDA | 开发板丝印27；此版本使用27 |
| GY-521 VCC/GND | 3.3V/GND，共地 |
| EC11 A/B/SW | 丝印29/30/31；模块供电与上拉采用3.3V逻辑 |
| 4Ω3W喇叭 | 跨接板载SPEAKER_P/SPEAKER_N；两根输出线均不接GND |
| 显示器 | 开发板HDMI输出接显示器HDMI输入，显示器单独可靠供电 |
| 内部串口TX/RX | FPGA封装69/70，对接对应板载控制器 |
| 板载I²S DIN/WS/BCLK | FPGA封装54/55/56 |
| 板载功放使能PA_EN | FPGA封装51 |

传感器供电灯只说明有电，不代表I²C已通信。模块接口使用SCL/SDA；XCL/XDA为辅助总线。传感器代码检查地址0x68及0x69，并按WHO_AM_I识别0x68/0x70。

本版FPGA入口通过串口接收24位琴键状态；原先MPR121触摸方案未作为本版直接输入模块实现。USB键盘/触摸屏需要匹配的USB Host平台程序，不能仅由普通扩展坞替代USB主机。

随附触摸适配器针对MPI7002报告格式编写，USB VID/PID为0x0484/0x5750；其他型号的触摸屏需要对应设备信息和报告解析。
